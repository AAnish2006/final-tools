Frequently Asked Questions

How do I convert HEX to RGB or HSL?

Enter your 6-character or 3-character HEX code (e.g. #2563EB or #F00) in the input or use the color picker. Our tool synchronously calculates the equivalent RGB decimal triplets (rgb(37, 99, 235)) and HSL percentages (hsl(221, 83%, 53%)) in real time.

What is WCAG 2.1 color contrast compliance?

The Web Content Accessibility Guidelines (WCAG) require sufficient contrast between text and background colors for readability. Level AA requires a minimum ratio of 4.5:1 for normal body text and 3:1 for large text (18pt or 14pt bold). Level AAA requires 7:1 for normal text and 4.5:1 for large text.

What are color tints and shades?

A tint is created by adding pure white to a base color (increasing lightness), while a shade is created by adding pure black (decreasing lightness). These help designers build consistent monochromatic design systems.
