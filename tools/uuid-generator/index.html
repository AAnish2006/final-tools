Frequently Asked Questions
What is a UUID v4?
A UUID (Universally Unique Identifier) version 4 is a 128-bit label generated using cryptographically strong pseudo-random numbers. The chance of duplicate collision is virtually zero: you would need to generate 1 billion UUIDs every second for 85 years to have a 50% probability of a single collision.
Is this UUID generator cryptographically secure?
Yes, 100%. All UUIDs are generated directly in your browser using the native Web Crypto API (crypto.randomUUID() and crypto.getRandomValues()), guaranteeing OS-grade cryptographic randomness with zero network requests.
What is the difference between a UUID and a GUID?
A GUID (Globally Unique Identifier) is Microsoft's implementation of the RFC 4122 UUID standard. In practice, GUID and UUID v4 refer to the same 128-bit randomized identifier format.
What is a Unix Timestamp?
The Unix Timestamp (or Epoch) is the total number of seconds elapsed since January 1, 1970 00:00:00 UTC. It provides an unambiguous, timezone-agnostic representation of time used across databases, JWT tokens, and APIs.
